# Orbit Hub device compatibility

This list covers mice marked supported or Bridge-required in the [device catalog bundled with Orbit Hub](../src/features/hardware-test/supported-devices-data.ts). Features vary by model, firmware, and connection type. Connect your device to see the controls Orbit Hub can read and change.

- **Supported** means the bundled catalog lists the model as supported. Desktop Chrome or Edge is the usual starting point for WebHID. Some models or connection types may need the desktop companion.
- **Requires Bridge** means the catalog lists the model as requiring the [desktop companion](../README.md#desktop-companion).

Models outside this list may have experimental drivers or be awaiting verification.

## Keyboards

Orbit Hub detects supported keyboards through their device-specific drivers. This table tracks mice. To check a keyboard, open [Orbit Hub](https://trashpenguin.github.io/orbit-hub/), select **Add device**, and check which controls appear for your model.
